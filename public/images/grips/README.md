# 握法插圖

依使用者提供的三張握法照片，以 ImageGen 分別重繪德式、法式、美式握法；不是樂器實拍照片。

圖像要求摘要：斜上方視角，忠於參考照片的雙手姿勢，兩支木質鼓棒的尖端分開、不交叉；深綠線條、米色背景與低彩度教學插畫。

- `german.webp`：手背向上、掌心向下、手肘較外開。
- `french.webp`：掌心相對、拇指向上、鼓棒平行。
- `american.webp`：手掌與手肘位置介於兩者之間。

圖片有透視；文字中的 90°／45° 為鼓面平面上的方向概念，不是直接量測圖片中的角度。原始參考文章：https://jeremydrums.pixnet.net/blog/posts/5053459908

真實樂器照片不使用生成式重繪；其來源與去背紀錄另見 `../IMAGE_SOURCES.json`。
